# Password Generator

این پروژه شامل یک برنامه تولید رمز عبور است که با زبان پایتون نوشته شده است.


## انواع رمزهای قابل تولید

- **Random Password**: رمز تصادفی شامل حروف بزرگ/کوچک، اعداد و نمادها (قابل تنظیم)
- **Memorable Password**: رمز ساخته‌شده از چند کلمه‌ی تصادفی انگلیسی (قابل تنظیم با جداکننده و حروف بزرگ)
- **Pin Code**: رمز عددی با طول دلخواه
```
PasswordGenerator (کلاس پایه)
├── RandomPasswordGenerator
│   └── generate() ← رمز تصادفی
├── MemorablePasswordGenerator
│   └── generate() ← رمز کلمه‌ای
└── PinCodeGenerator
    └── generate() ← رمز عددی
```
## وابستگی ها

- Python 3.7 یا بالاتر
- NLTK (Natural Language Toolkit)


## نصب و اجرا

ابتدا مطمئن شوید که تمام وابستگی‌های مورد نیاز را نصب کرده‌اید

```bash
pip install -r requirements.txt
```
