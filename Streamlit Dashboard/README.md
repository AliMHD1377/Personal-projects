# 🔐 برنامه تولیدکننده رمز عبور | Password Generator

این پروژه یک وب‌اپلیکیشن کاربردی و ساده برای ساخت انواع رمزهای عبور امن است که با استفاده از پایتون و فریم‌ورک **Streamlit** توسعه یافته است.


## ✨ ویژگی‌ها (Features)

برنامه دارای ۳ حالت مختلف برای تولید رمز عبور است:

1. 🔢 **کد پین (Pin Code):** 
   - تولید پسوردهای تماماً عددی با طول دلخواه (بین ۴ تا ۲۰ رقم).
2. 🎲 **رمز عبور تصادفی (Random Password):** 
   - تولید پسورد پیچیده تصادفی.
   - امکان فعال/غیرفعال‌سازی اعداد و نمادها (Symbols).
3. 🧠 **رمز عبور قابل یادآوری (Memorable Password):** 
   - تولید پسوردهایی ترکیبی از کلمات خوانا جهت به خاطر سپردن آسان‌تر.
   - قابلیت تعیین تعداد کلمات، کاراکتر جداکننده (Separator) و بزرگ‌نویسی حروف (Capitalize).

## 🚀 راه اندازی و اجرا (Installation & Run)

برای اجرای این پروژه روی سیستم خود، مراحل زیر را دنبال کنید:

### ۱. کلون کردن یا دانلود پروژه
پروژه را دانلود کرده و وارد پوشه اصلی آن شوید.

### ۲. نصب پیش‌نیازها
ابتدا کتابخانه‌های مورد نیاز را از طریق فایل `requirements.txt` نصب کنید:

```bash
pip install -r requirements.txt
```

### ۳. اجرای برنامه
با استفاده از دستور زیر در ترمینال، برنامه Streamlit را اجرا کنید:

```bash
streamlit run src/app.py
```

پس از اجرای این دستور، برنامه به صورت خودکار در مرورگر شما (معمولاً در آدرس `http://localhost:8501`) باز خواهد شد.
