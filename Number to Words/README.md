# به نام خدا
# مبدل عدد به حروف | Number to Words Converter

یک اسکریپت پایتون که یک عدد صحیح مثبت (حداکثر ۱۲ رقم) را با استفاده از رویکرد بازگشتی (Recursion) به معادل حروفی انگلیسی آن تبدیل می‌کند.

## نگاه کلی

این پروژه نشان می‌دهد که چگونه بازگشت می‌تواند مسئله تبدیل عدد به حروف را به شکلی ظریف و تمیز حل کند. به‌جای استفاده از زنجیره‌های طولانی if و elif، برنامه بزرگ‌ترین مقیاس قابل‌اعمال (Hundred، Thousand، Million، Billion) را پیدا می‌کند، عدد را می‌شکند و باقی‌مانده را به‌صورت بازگشتی پردازش می‌کند.

## ساختار پروژه

```
Number to Words/
├── README.md
└── src/
    ├── constants.py     # نگاشت‌های کلمات (UNDER_20، TENS، ABOVE_100)
    └── main.py          # منطق اصلی و نقطه ورود برنامه
```

## پیش‌نیازها

- پایتون نسخه ۳.۷ یا بالاتر
- هیچ کتابخانه جانبی مورد نیاز نیست

## نحوه اجرا

ترمینال را باز کنید، به پوشه src بروید و اسکریپت را اجرا کنید:

- cd src
- python main.py

سپس یک عدد صحیح مثبت وارد کنید:

- Enter a Number: 12345



## محدوده ورودی معتبر

حداقل: 0

حداکثر: 999,999,999,999 (۱۲ رقم)

اگر عدد خارج از این محدوده باشد، برنامه پیام Number out of range را چاپ می‌کند.
