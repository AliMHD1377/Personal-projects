# 🎮 Tic Tac Toe

یک بازی ساده‌ی **دوز (Tic Tac Toe)** که با زبان Python و با استفاده از مفاهیم **برنامه‌نویسی شیءگرا (OOP)** ساخته شده است.

در این بازی دو بازیکن `X` و `O` به صورت نوبتی بازی می‌کنند و بازیکن شروع‌کننده به صورت تصادفی انتخاب می‌شود.

## ✨ امکانات

- 🎮 بازی دو نفره در محیط ترمینال
- 🎲 انتخاب تصادفی بازیکن شروع‌کننده
- 🔄 تغییر نوبت بین بازیکنان
- ✅ بررسی برنده شدن در سطرها، ستون‌ها و قطرها
- 🤝 تشخیص حالت مساوی
- ⚠️ جلوگیری از انتخاب خانه‌های قبلاً استفاده‌شده
- 📋 نمایش وضعیت صفحه بازی در هر نوبت

## 📦 پیش‌نیازها

برای اجرای این پروژه فقط **Python 3** مورد نیاز است.

هیچ کتابخانه یا پکیج خارجی برای اجرای پروژه نیاز نیست.

این پروژه فقط از ماژول داخلی `random` پایتون استفاده می‌کند.
