## ⚙️ پیش‌نیازها

- Python 3.7+
- Streamlit (فقط برای داشبورد)

برای نصب بسته های لازم دستور`pip install -r requirements.txt` را اجرا کنید

## 🚀 نحوهٔ اجرا

شبیه‌سازی آماری در ترمینال:

```bash
python src/monty_hall.py
```

داشبورد Streamlit:

```bash
streamlit run src/app.py
```
