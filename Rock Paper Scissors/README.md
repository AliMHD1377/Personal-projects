# بازی سنگ-کاغذ-قیچی (Rock, Paper, Scissors)

یک بازی ساده‌ی خط فرمان که کاربر مقابل کامپیوتر بازی می‌کند.  
کامپیوتر به‌صورت تصادفی یکی از سه گزینه‌ی «Rock»، «Paper» یا «Scissors» را انتخاب می‌کند و برنده بر اساس قوانین کلاسیک این بازی مشخص می‌شود.

## ساختار پروژه
```
Rock Paper Scissors/
│
├── src/
│   └── game.py       # کلاس اصلی بازی
│
└── README.md
```

## امکانات

- انتخاب کاربر با اعتبارسنجی کامل
- انتخاب تصادفی کامپیوتر
- نمایش انتخاب کامپیوتر
- تشخیص برنده با استفاده از لیست ترکیب‌های برنده 
- امکان بازی مجدد با انتخاب `y` یا `n`
- ساختار کلاسی و رعایت اصول شی‌گرایی


## پیش‌نیازها

- Python 3.9 یا بالاتر

python src/game.py
