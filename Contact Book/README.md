# 📒 دفترچه مخاطبین (Contact Book)

یک برنامه ساده **دفترچه مخاطبین** که با زبان **Python** و با استفاده از مفاهیم **برنامه‌نویسی شیءگرا (OOP)** ساخته شده است.

این برنامه به کاربر اجازه می‌دهد مخاطبین خود را از طریق یک رابط خط فرمان (CLI) مدیریت کند.

## ✨ امکانات

- ➕ اضافه کردن مخاطب جدید
- ✏️ ویرایش اطلاعات مخاطب
- 📋 نمایش لیست تمام مخاطبین
- 🗑️ حذف مخاطب
- 🚪 خروج از برنامه
- ⚠️ جلوگیری از ثبت مخاطب با نام تکراری
- 📊 نمایش تعداد کل مخاطبین


## 📦 پیش‌نیازها

برای اجرای این پروژه **هیچ کتابخانه یا پکیج خارجی نیاز نیست**.

تنها چیزی که برای اجرای برنامه نیاز دارید:

**Python 3**

## ▶️ نحوه اجرا

ابتدا Repository را Clone کنید


سپس وارد پوشه پروژه شوید:

```bash
cd "Contact Book"
```

برای اجرای برنامه، دستور زیر را در ترمینال وارد کنید:

```bash
python src/main.py
```

> برای اجرای این پروژه فقط **Python 3** مورد نیاز است و به هیچ کتابخانه یا پکیج خارجی نیاز ندارد.

## 📖 نحوه کار برنامه

هسته اصلی برنامه کلاس `ContactBook` است.

این کلاس اطلاعات مخاطبین را در یک `Dictionary` نگهداری می‌کند.

هر مخاطب با نام خود به عنوان کلید ذخیره می‌شود:

```python
self.contacts = {
    "Ali": {
        "phone": "09123456789",
        "email": "ali@example.com",
        "address": "Tehran"
    }
}
```
