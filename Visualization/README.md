## 📦 دیتاست‌ها

### ۱. دیتاست Titanic
اطلاعات مسافران کشتی تایتانیک (۸۹۱ ردیف، ۱۵ ستون). ستون‌های کلیدی:

| ستون | نوع | توضیح |
|------|-----|-------|
| `pclass` | int (دسته‌ای) | کلاس مسافر (۱، ۲، ۳) |
| `sex` | object | male / female |
| `sibsp` | int (گسسته) | تعداد خواهر/برادر یا همسر همراه |
| `parch` | int (گسسته) | تعداد والد یا فرزند همراه |
| `fare` | float (پیوسته) | قیمت بلیت |
| `embarked` | object | بندر سوار شدن: S (ساوتهمپتون)، C (شربورگ)، Q (کوئینزتاون) |
| `class` | category | First / Second / Third |
| `who` | object | man / woman / child |
| `adult_male` | bool | پرچم مرد بزرگسال |
| `alone` | bool | سفر به‌تنهایی |
| `embark_town` | object | نام کامل بندر |
| `alive` | object | yes / no |


### ۲. دیتاست Breast Cancer (scikit-learn)
۵۶۹ نمونه با ۳۰ ویژگی که از تصاویر دیجیتال هسته‌ی سلول استخراج شده‌اند. تارگت: `0 = بدخیم`، `1 = خوش‌خیم`.

ویژگی‌های کلیدی استفاده‌شده در این تمرین:

| ویژگی | معنی |
|-------|------|
| `mean radius` | میانگین شعاع هسته سلول |
| `mean texture` | میانگین ناهمواری شدت روشنایی پیکسل‌ها (بافت) |
| `mean smoothness` | میانگین صافی مرز هسته سلول |
| `mean fractal dimension` | پیچیدگی مرز هسته (تقریب خط ساحلی منهای ۱) |
| `worst concavity` | بدترین (بزرگ‌ترین) تقعر مرز هسته |

هر ویژگی سه نسخه دارد: `mean ...` (میانگین)، `... error` (خطا) و `worst ...` (بدترین مقدار).

### ۳. دیتاست Housing
داده‌های املاک با ستون‌هایی مثل:
